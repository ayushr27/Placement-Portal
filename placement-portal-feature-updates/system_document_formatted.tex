\section{Introduction and Objectives}
The \textbf{Job Portal \& Placement Site} aims to modernize and simplify the campus recruitment and placement process. This web-based system provides an interactive, secure, and efficient interface for students to browse available opportunities, apply for roles, and manage their placement activities in one place.

The \textbf{student-side module} specifically focuses on providing a seamless experience where students can access filtered job listings, check their eligibility automatically, and monitor application progress efficiently. It minimizes manual work and communication gaps between students and placement coordinators.

\subsection*{Objectives}
\begin{itemize}
  \item Provide a unified and responsive dashboard for all student placement activities.
  \item Ensure transparency in job eligibility, applications, and results.
  \item Enable efficient job filtering, searching, and application features.
  \item Deliver personalized insights, including ATS-based resume evaluation.
\end{itemize}

\section{Technology Used}

\subsection{Hardware Requirements}
The system is lightweight and web-based, ensuring compatibility across multiple devices:
\begin{itemize}
  \item \textbf{Client Devices:} Any system or smartphone capable of running a modern web browser (Chrome, Edge, Firefox).
  \item \textbf{Server Requirements:} 
  \begin{itemize}
    \item CPU: Quad-core processor or higher.
    \item RAM: Minimum 16 GB.
    \item Storage: SSD (minimum 512 GB).
    \item Bandwidth: Minimum 100 Mbps network connectivity.
  \end{itemize}
\end{itemize}

\subsection{Software Requirements}
The system uses a full-stack development architecture:
\begin{itemize}
  \item \textbf{Frontend:} ReactJS with Tailwind CSS for fast and modern UI development.
  \item \textbf{Backend:} FastAPI for building high-performance RESTful APIs.
  \item \textbf{Database:} MongoDB for managing student profiles, job listings, and applications.
  \item \textbf{Authentication:} JWT-based secure login system.
  \item \textbf{Version Control:} GitHub for source code management and CI/CD.
  \item \textbf{Integration:} Google APIs (Sheets and Forms) for job data management.
\end{itemize}

\subsection{Deployment Details}
The application is deployed using a \textbf{hybrid cloud approach}:
\begin{itemize}
  \item \textbf{Frontend:} Deployed on \textbf{Vercel}, leveraging its global CDN for optimal loading times and auto-build deployment from GitHub.
  \item \textbf{Backend:} Deployed on an \textbf{AWS EC2 instance} running a Dockerized FastAPI server behind an Nginx reverse proxy.
  \item \textbf{Security:} HTTPS enabled using AWS Certificate Manager, ensuring encrypted communication.
  \item \textbf{Scalability:} Load balancing handled via AWS Elastic Load Balancer, with auto-scaling groups to manage traffic surges.
\end{itemize}

\section{Important Modules of the Software}
\subsection{Student Home Module}
\begin{itemize}
  \item Personalized dashboard showing relevant jobs, profile completion status, and application summary.
  \item Filtering-based job search and application for students, enabling them to refine listings by company, salary, department, and eligibility.
  \item Quick navigation to important sections like profile editing, job listings, and ATS checker.
  
\end{itemize}

\subsection{Profile Management Module}
\begin{itemize}
  \item Allows students to enter and update personal, academic, and technical skill information.
  \item Ensures data consistency through form validation and real-time verification.
  \item Automatic eligibility recalculation based on academic parameters.
  \item Coordinators can approve or reject modifications to ensure data accuracy.
\end{itemize}

\subsection{Job Listings \& Application Module}
\begin{itemize}
  \item Displays live job openings from recruiters integrated via Google Forms or admin uploads.
  \item Filtering options by company, role type, CGPA, and department.
  \item Students can apply directly through integrated job links.
  \item Each job displays eligibility criteria, salary, and application deadline.
  \item Status updates reflect in real time, showing "Applied," "Shortlisted," or "Selected."
\end{itemize}

\subsection{ATS Resume Checker Module}
\begin{itemize}
  \item The \textbf{ATS (Applicant Tracking System) Checker} evaluates resumes by comparing them against the job description.
  \item It analyzes keyword relevance, skills overlap, and section completeness.
  \item Outputs:
  \begin{itemize}
    \item \textbf{ATS Score:} A numerical match percentage.
    \item \textbf{Job Fitness Rating:} Qualitative insights on resume suitability.
    \item \textbf{Improvement Suggestions:} Recommendations for keyword additions or structural improvements.
  \end{itemize}
  \item This helps students tailor their resumes to increase their selection probability.
\end{itemize}

\subsection{Notifications Module}
\begin{itemize}
  
  \item Built using an SMTP-based backend mailer integrated with FastAPI.
  \item Ensures all users receive verified and relevant placement communication.
\end{itemize}

\section{Types of Queries the System Can Handle}

The system is designed to handle a variety of queries from students, recruiters, and administrators efficiently. Key query types include:

\begin{itemize}
    \item \textbf{Job Queries (Students):} 
    \begin{itemize}
        \item Search for jobs based on company, role, salary, location, and department.
        \item Check eligibility criteria for specific jobs..
    \end{itemize}
    
    \item \textbf{Profile Queries (Students):} 
    \begin{itemize}
        \item Retrieve and update personal, academic, and skill information.
        \item Check profile completion and verification status.
    \end{itemize}
    
    \item \textbf{Data Queries (Students):} 
    \begin{itemize}
        \item Generate ATS resume feedback and job fitness reports.
        \item View historical application data and dashboard summaries.
    \end{itemize}
    
    \item \textbf{Candidate Queries (Recruiters):} 
    \begin{itemize}
        \item Access verified student profiles matching job requirements.
        \item Filter candidates based on CGPA, department, and skills.
    \end{itemize}
    
    \item \textbf{Process Queries (Recruiters):} 
    \begin{itemize}
        \item Retrieve recruitment process guidelines and timelines.
        \item Communicate with placement cell for clarifications or updates.
    \end{itemize}
    
   
\end{itemize}

\section{Security Features and Testing}

\subsection{Implemented Security Features}
\begin{itemize}
  \item JWT tokens for authentication and session handling.
  \item Bcrypt for password hashing and protection against brute force attacks.
  \item Role-based access control to restrict unauthorized API access.
  \item HTTPS communication to prevent man-in-the-middle attacks.
  \item Input sanitization to protect against SQL/NoSQL injection.
\end{itemize}

\subsection{Testing Details}
To validate performance, the system underwent \textbf{Locust-based stress testing}.  
The test simulated 500 concurrent users performing operations such as login, job fetching, and profile access.

Results:
\begin{itemize}[itemsep=1pt, topsep=1pt, parsep=0pt, partopsep=0pt]
  \item Average RPS: 183.6 (Requests per Second)
  \item Failure Rate: 1\%
  \item Median Response Time: 140 ms
\end{itemize}

In addition, user testing was conducted with 30 students. They evaluated usability, performance, and responsiveness on multiple devices. Feedback confirmed the interface was smooth, intuitive, and visually clear.
